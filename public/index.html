Providers API

A Cloudflare worker API providing streaming URLs for movies and TV shows using TMDB IDs.

Docs Test Provider Env

API Documentation

GET /api/movie

Fetch stream for a movie. Optional sourceId.

/api/movie?tmdbId=299534&sourceId=superstream

GET /api/show

Fetch stream for a TV show episode. Optional sourceId.

/api/show?tmdbId=1399&season=1&episode=1&sourceId=superstream

GET /api/all

Fetch results from ALL providers. Includes flags: ["cors-allowed"].

/api/all?tmdbId=299534&type=movie
